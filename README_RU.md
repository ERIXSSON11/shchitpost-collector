# ShchitPost Collector — Telegram-бот

Бот периодически пытается получить ссылки с открытых страниц хештегов TikTok `#щитпост` и `#щп`, удаляет дубликаты и отправляет новые ссылки владельцу.

## Ограничения

- Страницы TikTok часто ограничивают автоматические запросы и могут менять HTML. Автосканирование — best effort, не гарантирует полный список публикаций.
- Этот шаблон сохраняет и отправляет ссылки, а не скачивает чужие видео или не удаляет водяные знаки.
- Скачивайте и распространяйте только видео, на использование которых у вас есть права/разрешение.
- Для стабильного промышленного поиска лучше использовать официальный/разрешённый источник данных, если он доступен для вашего сценария.

## 1. Создать Telegram-бота

1. Откройте https://t.me/BotFather
2. Отправьте `/newbot` и выполните инструкции.
3. Скопируйте токен. Никому его не показывайте.

## 2. Узнать свой Telegram user ID

Напишите `userinfobot` в Telegram: https://t.me/userinfobot. Возьмите числовой ID, не username.

## 3. Загрузить проект в GitHub

1. Создайте аккаунт на https://github.com
2. Создайте новый репозиторий, например `shchitpost-collector`.
3. Загрузите `bot.py`, `requirements.txt`, `Dockerfile` и `.gitignore`.

## 4. Развернуть в Railway

1. Откройте https://railway.app и войдите.
2. Создайте новый проект из GitHub-репозитория.
3. В настройках сервиса добавьте Variables:
   - `BOT_TOKEN` = токен от BotFather
   - `OWNER_ID` = ваш числовой Telegram ID
   - `POLL_HOURS` = `6`
   - `DB_PATH` = `/data/videos.db`
4. Добавьте постоянный Volume и подключите его к `/data`, чтобы база SQLite переживала перезапуски.
5. Убедитесь, что сервис использует Dockerfile и запустился без ошибок.
6. Откройте своего бота в Telegram и отправьте `/start`, затем `/scan`.

Облачный хостинг, как правило, платный для постоянной работы. Проверьте актуальную стоимость и условия платформы перед запуском.

## Команды

- `/start` — инструкция
- `/scan` — немедленная проверка хештегов
- `/add ССЫЛКА` — вручную сохранить ссылку на ролик
- `/latest` — показать последние 10 ссылок
- `/count` — количество сохранённых ссылок
- `/help` — помощь

## Безопасность

Не загружайте токен в публичный репозиторий и не отправляйте его другим людям. Если токен случайно утёк, отзовите его через BotFather и создайте новый.
